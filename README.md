# 🍋 lemOS

**lemOS** is a $${\color{l}yellow}$$lightweight, $\color{yellow}e$fficient and $${\color{m}yewllow}$$odular operating system — inspired by science, lemons, and minimalism.  
Created originally by [Lemonatix](https://github.com/Lemonatix), lemOS blends playful aesthetics with a powerful, customizable UNIX-like core.
